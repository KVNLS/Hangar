HANGAR · DESIGN SYSTEM v0.1
Tokens & components
A workspace for running many coding agents in parallel against a live simulator. Calm, dense, keyboard-first. Every value below maps 1:1 to a GPUI primitive: flat fills, 1px borders, radii ≤ 10px, one drop shadow for overlays. No blur, no gradients, no transparency except the modal scrim.
ASSUMPTIONS
· “Hangar” stands in for [NAME]; swap freely.
· Sample project: pantry-ios (SwiftUI) + pantry-android (Compose).
· Agent marks are neutral monograms (CC, CX, GM) — replace with licensed vendor icons.
· Icons: Lucide (ISC) — ship as SVG assets in GPUI.
· One accent (indigo). State hues are reserved for agent status and diffs only.
