Run your coding agents in parallel.

Each in its own worktree, each with its own simulator. Hangar runs Claude Code, Codex, OpenCode and Gemini CLI side by side, and lets them check their UI work on a real iOS simulator or Android emulator.

Claude Code added an empty state to an Expo app, ran the tests, built the app with Hangar's build_and_run tool and checked the result on the simulator itself.

Your agents, your accounts

Hangar runs the CLIs you already use. It never proxies a model call.

One task, one worktree

Every workspace is a Git worktree on its own branch, so agents never step on each other.

Built for mobile

Each workspace can get its own iOS simulator or Android emulator, live in the window.

Native and fast

Rust and GPUI, no Electron. Simulator frames are painted straight from their IOSurface.

Parallel workspaces

As many agents as you like, none in each other's way.

Add a repository, start workspaces and pick an agent for each. Hangar creates the worktree and branch, starts the agent in it, and keeps projects, workspaces and sessions across restarts. The sidebar shows who is working, waiting for approval or done, and macOS notifications tell you when one needs you.

Devices in the window

Agents that test on the simulator themselves.

Every agent gets a hangar MCP server: screenshots, taps, swipes, typing, logs and build_and_run. Devices are pooled and shared fairly, and every call goes through the same permission prompts as any other tool.

  • iOS simulator through CoreSimulator, with a simctl fallback
  • Android emulator over gRPC, with an adb fallback
  • ⌘R builds and runs Xcode, Gradle, React Native and Expo projects

Live changes and review

Review each change on its own.

Files are watched as agents write them. The review screen shows the workspace's diff, split or inline with syntax highlighting, and lets you commit, push, rebase, merge or open a pull request.

Orchestration

Best-of-N, queues and an approvals inbox.

Start the same task with several agents and compare their attempts side by side. An overview shows every agent, a queue caps how many run at once, and usage and cost are tracked per session and per day.

Supported agents

Bring the CLIs you already use.

Run each as a plain terminal, or as a structured chat through the Agent Client Protocol, with tool-call cards, permission prompts, model pickers and session resume.

  • Claude Code
  • Codex CLI
  • OpenCode
  • Gemini CLI
  • Ollama models via OpenCode

Install

Up and running in a minute.

  1. Download

    Get Hangar-<version>-arm64.dmg from the latest release.

  2. Install

    Open the disk image and drag Hangar to Applications.

  3. First launch

    Builds are not notarized yet: right-click Hangar › Open › Open, or run

    xattr -dr com.apple.quarantine /Applications/Hangar.app

Prefer to build it yourself?

git clone https://github.com/KVNLS/Hangar.git
cd Hangar
cargo run -p hangar-app
